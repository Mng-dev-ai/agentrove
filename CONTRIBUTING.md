# Contributing to Claudex

Thanks for your interest in contributing to Claudex!

## Quick Start

```bash
git clone https://github.com/Mng-dev-ai/claudex.git
cd claudex
```

## Pull Requests

1. Fork the repository
2. Create a branch from `main`
3. Commit and push your changes
4. Open a descriptive PR

## Reporting Issues

Please include reproduction steps, expected behavior, and your environment.
