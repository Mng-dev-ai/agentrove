# Vendored fonts

These fonts are bundled for the in-app terminal so Nerd Font icon glyphs
(file-type icons, prompt symbols) render without relying on a font installed on
the user's machine.

## JetBrainsMono Nerd Font Mono (Regular, Bold)

  (https://github.com/JetBrains/JetBrainsMono), licensed under the
  **SIL Open Font License 1.1**. Full text: `LICENSE-JetBrainsMono-OFL.txt`.
- Icon glyphs patched in by the **Nerd Fonts** project
  (https://github.com/ryanoasis/nerd-fonts), patcher licensed under the
  **MIT License**. The font binaries remain under the OFL above.

Source: https://github.com/ryanoasis/nerd-fonts/releases (v3.2.1)
